# 🎬 StreamFlix Content Analytics

## 📊 Project Overview

StreamFlix Content Analytics is a data analytics project developed to analyze
subscriber engagement, content performance, customer churn, ratings and reviews,
catalogue composition, and content investment.

The project uses Python, SQL, Power BI, and DAX to transform streaming data
into meaningful business insights.

---

## 🎯 Project Objectives

- Analyze subscriber engagement and viewing behavior
- Identify high-performing content and genres
- Analyze subscriber churn and plan-level behavior
- Understand ratings and customer review sentiment
- Analyze catalogue composition and content investment
- Build an interactive Power BI dashboard
- Generate actionable management insights

---

## 🛠️ Tools & Technologies

- Python
- SQL
- Power BI
- DAX
- Excel / CSV
- Data Visualization
- Exploratory Data Analysis
